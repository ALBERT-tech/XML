📄 Читалка способов закупки (223-ФЗ)

Вставьте ссылку на печатную форму (view.html) — приложение найдёт и загрузит XML

💡 Про режимы
• Локальный прокси — запустите в терминале python proxy.py, затем жмите «Загрузить». Работает надёжнее всего, не зависит от сторонних сервисов.
• Публичный прокси — пробовать, если нет возможности запустить Python. Может быть нестабилен / ограничен по частоте запросов.
• Прямой запрос — почти всегда падает с CORS-ошибкой, т.к. zakupki.gov.ru не отдаёт Access-Control-Allow-Origin.
• Ручная загрузка — если нужно посмотреть уже скачанный XML.
✨ Выберите режим и нажмите «Загрузить».
⚡ Для работы с zakupki.gov.ru рекомендуется локальный прокси (python proxy.py).
