📄 Читалка способов закупки (223-ФЗ)

Вставьте ссылку на печатную форму (view.html) — приложение само найдёт и загрузит XML с данными

💡 Как это работает
• Вы вставляете ссылку, которую видите в браузере (с view.html).
• Приложение автоматически заменяет view.html на viewXml.html и загружает XML-файл с портала.
• Из XML извлекаются все способы закупки: код + название.
✨ Вставьте ссылку на печатную форму и нажмите «Загрузить».
Пример по умолчанию — положение с реестровым номером 1130016483 (версия 31).
⚡ Работает напрямую с API zakupki.gov.ru. При проблемах с загрузкой предлагается альтернативный ручной режим.
